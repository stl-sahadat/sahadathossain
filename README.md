Built with the iconic high-velocity **Framer Omnira Cyber Cyan** (`#00F0FF`) digital aesthetic, featuring interactive 3D platforms, an end-to-end synchronized Admin Matrix, and a resilient enterprise-grade hybrid backend.

---

## ⚡ Tech Stack Architecture

- **Frontend & App Framework:** [Next.js 15](https://nextjs.org/) (App Router, Server Components & Dynamic Route Handlers) + [React 19](https://react.dev/)
- **Alternative SPA Engine:** [Vite 6](https://vitejs.dev/) with React 19
- **Database & Data Layer:** [Prisma ORM 6](https://www.prisma.io/) with MySQL schema and resilient automatic disk fallback
- **Interactive Physics:** [Lenis Smooth Inertia Momentum Scroll](https://lenis.darkroom.engineering/)
- **UI & Design:** Custom Tailwind CSS, CSS Grid, Film Grain Shader, Continuous Hazard Hatch Stripes
- **Icons:** Custom SVG Cyber HUD Badges & [Lucide React](https://lucide.dev/)
- **Live Widgets:** Dhaka GMT+6 Synchronized Digital Clock, Interactive Isometric Services Diamond Stack, Live Admin Matrix

---

## 🛠️ Key Features

1. **Monolithic Cyber Cyan Aesthetics:** Modeled with 100% pixel fidelity to Framer Omnira with glowing neon cyan accents, hazard boundary lines, and sleek cyber typography (`Chakra Petch`, `Orbitron`, `Inter`).
2. **Dynamic Admin Matrix Portal (`/admin`):**
   - Live synchronization across all routes: Home (`/`), Works (`/works`), About (`/about`), Gallery (`/gallery`), Contact (`/contact`), and Footer.
   - Project manager, Video showcase manager, Service pillars editor, Testimonials/Reviews, and Brand identity editor.
3. **Resilient Data Layer:**
   - Next.js 15 Route Handlers: `/api/portfolio`, `/api/upload`, `/api/auth/login`.
   - Prisma ORM connects seamlessly to MySQL. If MySQL is not running locally, it gracefully persists to `src/data/portfolio-store.json` with zero downtime.

## 🚀 Getting Started

### 1. Installation

```bash
npm install
```

### 2. Running Development Servers

```bash
# Run Next.js 15 Server (Default & Recommended)
npm run dev:next

# Or Run Vite SPA Dev Server
npm run dev
```

### 3. Production Build

```bash
# Build Next.js 15 Production Bundle
npm run build:next

# Start Next.js 15 Production Server
npm run start:next
```

### 4. Database Setup (Optional MySQL with Prisma)

```bash
# Generate Prisma Client
npm run prisma:generate

# Push Schema to MySQL
npm run prisma:push
```
